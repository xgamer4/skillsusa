# OceanDestruction2

# How to use
### Linux
Open terminal and type `./ocean-and-destruction-2`
### Windows
Open command prompt in this directory and type `ocean-and-destruction-2.exe`


# Build, test, and run with node
- Ensure you have node.js installed
## Run from typescript
2. Run `npm i`
3. Run `npm run dev`
# Build and run javascript
1. Run `npm i`
2. `npm run build`
3. `npm run start`
